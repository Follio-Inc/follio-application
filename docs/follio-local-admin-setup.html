Set up the app and sign in

  11. Each day after that

  1. What was sent to you

    This page comes with two other private items. You need both.

    • A file named .env.local. Save it. Do not rename it, edit it, commit it, or forward it.
    • An email and a password, in a separate message.
    Carissa carissa.c@follio.me
    Padmaja padmaja.m@follio.me

    Use that exact email. The password is the one sent to you, including any capital letters and symbols.

    These logins work only in the local app on your computer. They do not work on follio.me.

  2. Open a terminal

    A terminal is the window where you type the commands in this guide. Leave it open while the app is running.

    Mac

    1. Press Command + Space.
    2. Type Terminal.
    3. Press Return. A window with a blinking cursor opens.

    Windows

    1. Click the Start button.
    2. Type PowerShell.
    3. Open Windows PowerShell. Do not open Command Prompt.

    You are ready when you see a blinking cursor and can type.

  3. Install Git

    Git downloads the project. Check whether it is already installed:

    git --version

    If you see a version, such as git version 2.39.0, Git is installed. Go to the next step.

    Mac, if the command is not found

    1. In Terminal, run: 
      xcode-select --install
    2. A window appears. Click Install, then Agree.
    3. Wait until it finishes. This can take several minutes.
    4. Close Terminal, open it again, and run git --version.

    If that command does nothing, download the Mac installer from https://git-scm.com/download/mac, open the downloaded file, and click through the installer. Then open a new Terminal and run git --version again.

    Windows, if the command is not found

    1. Open https://git-scm.com/download/win. The download of 64-bit Git for Windows Setup starts on its own.
    2. Open the downloaded .exe file.
    3. Click Next through the installer. Keep the default options. On the screen about adjusting your PATH, leave Git from the command line and also from 3rd-party software selected.
    4. Close PowerShell, open it again, and run git --version.

  4. Install Node.js 20

    Node.js runs the app. The installer also installs npm, which downloads the project’s libraries. You do not install npm by itself.

    The large download button on the Node.js homepage often installs a newer version. This project needs version 20. Use the version 20 folder below, not the homepage button.

    Open this page: https://nodejs.org/dist/latest-v20.x/

    Mac

    1. Click the Apple menu, then About This Mac.
    2. Read the chip line.
      • If it says Apple M1, M2, M3, or M4, download the file whose name ends in darwin-arm64.pkg.
      • If it says Intel, download the file whose name ends in darwin-x64.pkg.
    3. Open the downloaded .pkg file.
    4. Click Continue, then Install. Enter your Mac password if asked.
    5. When it says the installation was successful, click Close.
    6. Quit Terminal completely, then open a new Terminal window.

    Windows

    1. On the same page, download the file whose name ends in x64.msi.
    2. Open the downloaded file.
    3. Click Next. Accept the license. Leave the default install location and the default features, including Add to PATH.
    4. Click Install, then Finish.
    5. Close PowerShell completely, then open a new PowerShell window.

    Check, in the new terminal window

    node -v
npm -v

    node -v must print v20 followed by more numbers, for example v20.19.0. npm -v must print 10 or higher, for example 10.8.2.

    If node -v prints v18, v22, v24, or any version that does not start with v20, the wrong installer was used. Download the version 20 installer from the link above and run it again. Then close the terminal, open a new one, and run node -v again.

  5. Confirm GitHub access

    1. Open https://github.com/ and sign in. Create a free account first if you do not have one.
    2. Open the invitation email for the repository Follio-Inc/follio-application and click Accept invitation.
    3. Confirm you can open https://github.com/Follio-Inc/follio-application. You should see the code, not a 404 page.

    If that page loads, your GitHub account can download the project.

  6. Download the code

    This puts a folder named follio-application inside Documents. Skip this step if that folder is already on your computer, and continue at the next step.

    Mac

    cd ~/Documents
git clone https://github.com/Follio-Inc/follio-application.git
cd follio-application

    Windows PowerShell

    cd $HOME\Documents
git clone https://github.com/Follio-Inc/follio-application.git
cd follio-application

    The first time, a browser window or a GitHub sign-in window opens. Sign in with the GitHub account that accepted the invitation. Approve access if asked.

    The command finishes when the terminal shows a new prompt and no error. In Documents you can see a folder named follio-application.

  7. Switch to the develop branch

    The branch name is develop. Every command from here on is typed while you are inside the follio-application folder.

    Mac

    cd ~/Documents/follio-application
git checkout develop
git pull origin develop
git branch

    Windows PowerShell

    cd $HOME\Documents\follio-application
git checkout develop
git pull origin develop
git branch

    The last command prints a list of branches. A star must sit next to develop, like this: * develop.

  8. Add the environment file

    The app will not recognize your login until this file is in the project folder. The file is the .env.local that was sent with this page.

    When this step is done, the folder looks like this:

    follio-application/ package.json .env.local ← the file you were sent .env ← a copy of that same file

    Both files sit next to package.json. They must contain the same text. Do not fill them in from .env.example.

    If the download lost the leading dot

    Some chat apps save the file as env.local instead of .env.local. Rename it so the name starts with a dot before you continue.

    Mac

    1. Move the received file into the project folder. If it is in Downloads, run: 
      mv ~/Downloads/.env.local ~/Documents/follio-application/.env.local
      If the downloaded name has no leading dot, use ~/Downloads/env.local in that command instead.
    2. Make the second copy: 
      cd ~/Documents/follio-application
cp .env.local .env
ls -a

    Files that start with a dot are hidden in Finder. In Finder, press Command + Shift + . to show them.

    Windows

    1. If the file is in Downloads, run this in PowerShell: 
      copy $HOME\Downloads\.env.local $HOME\Documents\follio-application\.env.local
      If the downloaded name has no leading dot, use $HOME\Downloads\env.local instead.
    2. Make the second copy: 
      cd $HOME\Documents\follio-application
copy .env.local .env
Get-ChildItem -Force

    ls -a on Mac, or Get-ChildItem -Force on Windows, lists both .env and .env.local.

    Do not run Docker. Do not run npm run db:migrate or npm run db:seed. Those create a separate empty database, and this login will not be in it.

  9. Install and start the app

    From inside follio-application:

    npm install
npx prisma generate
npm run dev

    What each command does:

    • npm install downloads the libraries. The first run can take a few minutes.
    • npx prisma generate prepares database code on your computer. It does not change the shared database.
    • npm run dev starts the app and keeps running.

    Leave this terminal open. The app is ready when the terminal prints a local address: http://localhost:3000.

    To stop the app later, click the terminal and press Ctrl + C.

  10. Sign in

    1. Open a browser.
    2. Go to http://localhost:3000/admin/sign-in. Type that address. Do not open follio.me.
    3. Enter your email: carissa.c@follio.me or padmaja.m@follio.me.
    4. Enter the password from the separate message.
    5. Continue until the page changes.

    You are signed in when the address is http://localhost:3000/admin and the left sidebar shows Overview, Developer, and Users.

    Open Developer for the engineering tools, or go directly to http://localhost:3000/admin/developer.

  11. Each day after that

    Mac

    cd ~/Documents/follio-application
git checkout develop
git pull origin develop
npm run dev

    Windows PowerShell

    cd $HOME\Documents\follio-application
git checkout develop
git pull origin develop
npm run dev

    When the terminal shows http://localhost:3000, open http://localhost:3000/admin/sign-in.

    After a pull, if the terminal says packages changed, run npm install once before npm run dev.

If something fails

What you see What to do
node -v is not v20 Install the version 20 package from nodejs.org/dist/latest-v20.x, then close the terminal and open a new one.
git or node is not recognized The install finished in an old window. Close the terminal and open a new one.
GitHub asks you to sign in, or clone says authentication failed Sign in with the GitHub account that accepted the repository invitation, then run the clone command again.
Repository page is a 404 The invitation has not been accepted yet, or a different GitHub account is signed in.
Sign-in says the account was not found The address must be http://localhost:3000/admin/sign-in. The email must match exactly. .env and .env.local must both be the file you were sent. Press Ctrl + C, run npm run dev again, and retry.
Password is rejected Retype the password from the message. Include capitals and symbols. The email and password are a pair; another person’s password will not work.
Port 3000 is already in use Another copy of the app is running. Find that terminal and press Ctrl + C, then run npm run dev again.
The browser cannot connect to localhost:3000 npm run dev is not running, or the terminal was closed. Start it again from the project folder.
